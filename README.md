### [Commerce Data Platform](https://github.com/CamerenGreen/commerce-data-platform)
**Python · FastAPI · PostgreSQL · MongoDB · Redis · Docker**

A commerce backend and analytics dashboard that assigns each database a specific responsibility: PostgreSQL for orders and inventory, MongoDB for behavioral events, and Redis for cached analytics.

- Protects checkout with serializable transactions, row locking, and database constraints.
- Combines SQL and document aggregations into funnel analytics, with cache invalidation and expiration.
- Includes architecture documentation and GitHub Actions checks for linting, unit tests, and container health.

### [Flick Picker](https://github.com/CamerenGreen/Flick-Picker)
**Python · FastAPI · SQLite · JavaScript · Chrome Extensions · Docker**

A full-stack movie and TV recommender with a browser demo and Chrome extension.

- Implements a weighted TF-IDF recommendation model with cosine similarity, using watch history and ratings to rank unseen titles.
- Integrates TMDB search and catalog imports, with API credentials kept on the backend.
- Includes API tests, automated extension packaging, and Render deployment configuration.

### [TrainTrace BKK](https://github.com/CamerenGreen/TrainTrace-BKK)
**TypeScript · React · Vite · SVG · Graph Algorithms**

An interactive Bangkok BTS/MRT journey planner covering seven rail lines.

- Ranks routes by estimated journey time, fare, or transfers, accounting for interchanges and ticket grouping.
- Provides a zoomable SVG map, route highlighting, and keyboard-accessible station search.
- Tests graph topology, fare calculations, branches, loops, and timezone behavior; clearly labels travel information as planning estimates.
